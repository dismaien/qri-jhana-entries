# Submission Checklist

Use this before sending anything to QRI.

## Required Per Submission

- one MP4 or MOV file, up to 2 minutes
- clear time tags for every jhana segment in the video
- one written explanation between 200 and 1,000 words
- brief method context describing how the state was induced or accessed

## Body Jhana Checks

For J1-J4 specifically:

- include a visible body reference or avatar
- make internal volume legible, not just surface glow
- ensure the visual reads as bodily sensation rather than generic spirituality

## Render Checks

- confirm the right entry and time tags
- confirm the latest preview MP4 exists
- regenerate stills and a board for quick review
- watch the whole video once without stopping
- check that transitions feel intentional, not just parameter interpolation
- for `Somatic Arc`, check that tactile marks read differently across J1-J4 rather than as generic texture
- for `Formless Mirror`, check that lensing and field lines remain subtle enough that J7-J8 still feel sparse

## Writeup Checks

- explain what the main visual elements mean
- name the phenomenological features being prioritized
- describe the meditation route or induction method honestly
- replace generic first-person language with your own actual practice details
- keep any method note explicitly marked as a placeholder until it has been personalized

## Repo Commands

For a quick local pass:

```bash
npm run build
npm run refresh:somatic
npm run refresh:formless
npm run refresh:induction
npm run inventory:renders
npm run package:submissions
```

## Packaging Pass

- confirm each entry has the expected MP4, stills, and board before packaging
- gather the latest submission-ready files into `submission-package/`
- open the packaged folders and check that each writeup matches the video beside it

## Final Human Review

Before submitting:

- decide which entries are strongest enough to use
- trim anything that looks decorative but not phenomenologically informative
- verify the written explanations still match the latest renders
- make sure the file names and tags are easy to understand
