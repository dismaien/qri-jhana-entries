## What Still Looks Most Important

- J1-J4 should keep a body reference, but not a flat silhouette. The official brief specifically rewards internal volume and energy-body rendering.
- The contest is still strongly biased toward phenomenal character over semantics, so symbolic overlays, chakras, sacred-geometry shortcuts, and metaphor-first imagery remain weak bets.
- The written explanation is still 25% of the score, which means each visual move should be interpretable in plain language rather than defended as pure aesthetics.

## Strongest Technical Levers

- QRI's tactile visualization work suggests a compact parameter set is already surprisingly informative: modality, location, temporal frequency, spatial frequency, envelope shape, and distribution of arising/ceasing.
- The same article suggests a practical body-language for the first four jhanas: waves, pins, needles, prickles, pressure blooms, and flowing blockages rather than generic glow.
- The attention field-lines note argues that attention is better treated as a dynamic field configuration than as a literal spotlight. For this repo, that points toward converging flow maps and weighted attractors instead of just moving cursors.
- The Oscilleditor manual keeps reinforcing three useful knobs for future versions: log-polar transforms, kernel-size variation by edges/depth, and frequency maps that vary across the image rather than globally.

## Design Implications For This Repo

- `Somatic Arc` should get a thicker volumetric shell and clearer modality changes across J1-J4. Right now it has energy, but not enough tactile specificity.
- J1 should read as latch + ignition, with denser prickling and sharper envelope attack.
- J2 should read as self-sustaining coherence, with less effort-signaling and more internally locked pulse fields.
- J3 should cool and broaden, drifting from sparkle into smooth pressure or liquid ease.
- J4 should reduce local contrast and become nearly uniform without going visually dead.
- `Formless Mirror` should probably borrow the field-line idea more explicitly so J5-J8 feel like changes in the structure of awareness rather than just dissolving particles.

## Near-Term Work Queue

- Add a pseudo-3D or Blender-assisted body shell for `Somatic Arc`.
- Introduce explicit tactile modality presets instead of relying only on palette and motion.
- Give each segment a more legible ADSR profile so transitions feel phenomenological, not interpolated.
- Prototype one field-line study for `Formless Mirror`, especially for J5 and J6.

## Bottom Line

The repo direction still looks right, but the next quality jump is not "more polish" in the generic sense. It is more tactile specificity for J1-J4 and more structurally legible awareness dynamics for J5-J8.
