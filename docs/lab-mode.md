# Lab Mode

`?lab=1` turns the app into a live remix surface.

Example:

- `http://127.0.0.1:4173/?entry=meditation-atlas&lab=1`

## What It Adds

- a floating `lil-gui` panel for creative tweaking
- URL-synced presets so a remix can be bookmarked or shared
- a reset action that returns the current preset to its default values

## Presets

- `Neutral`
  Baseline render behavior with no global remix.

- `Settling`
  Slower, softer, more spacious, lower-turbulence behavior.

- `Warmth`
  Slightly warmer palette with stronger bloom and gentler motion.

- `Vastness`
  Cooler, wider, thinner field behavior for open-awareness studies.

- `Electric`
  Higher energy, faster tempo, and more turbulence for sharper activation states.

## Remix Knobs

- `Hue Shift`
  Rotates the overall palette without changing the scene structure.

- `Energy`
  Pushes intensity and reduces some stillness.

- `Turbulence`
  Roughens the field and makes motion less laminar.

- `Spaciousness`
  Widens the scene and supports more panoramic reads.

- `Tempo`
  Speeds up or slows down the pulse language.

- `Flow`
  Lengthens or shortens directional traces.

- `Overlay`
  Strengthens or softens blooms, guide structures, and atlas motifs.

## Good Uses

- audition multiple moods for the same entry without editing source
- find a promising variant and then turn it into a dedicated new study
- generate different flavor directions for breath, metta, or open-awareness work
